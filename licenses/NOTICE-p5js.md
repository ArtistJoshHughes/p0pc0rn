- The file is `makeapp/p5.min.js`, the unmodified release build of p5.js 1.11.13. Its source code is published by the p5.js project:
  https://github.com/processing/p5.js (tag v1.11.13).
- p0pc0rn loads it as a separate file into each app's sandbox, so you can replace `makeapp/p5.min.js` with your own build of p5.js
